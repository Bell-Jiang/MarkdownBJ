# Markdown Learning Journal

## Overview

A journal used to learn markdown formatting in GitHub. There are no TODO, TBD, example.com or replacement placeholders.

## Features

- Headings
- Lists
- Images
- LaTeX

## Prerequisites

Use a web browser to read the journal on GitHub.

## Installation

Run these commands in a terminal to download the repository.

```bash
git clone https://github.com/YOUR-USERNAME/skills-communicate-using-markdown.git
cd skills-communicate-using-markdown
```

## Usage

Display the journal in a terminal with this command. On Windows PowerShell, use `Get-Content day-1.md` instead.

```bash
cat day-1.md
```

For formatted reading, open the Preview tab. Check or uncheck tasks by editing their Markdown and committing your changes.

## Expected Output

There are multiple levels of headings. Each level displays text at a different size.

```text
# Daily Learning

## Morning Planning
```

Click the branch button and then the new branch button to create a new branch. Click the Preview button while editing to preview markdown. Click links in Preview mode to check links. Make sure to open a pull request with a useful description.
